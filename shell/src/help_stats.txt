stats command help

Commands:
  stats
      Open the live stats view.
  stats period <ms>
      Set the refresh cadence used by the live stats view.

What you get:
  timestamp
  uptime
  configured and online processor counts
  per-processor busy permille
  memory totals and memory pressure

Examples:
  stats
  stats period 1000

Controls inside the live view:
  q
      Return to the shell.
  Esc
      Return to the shell.
  Ctrl-C
      Return to the shell.
