Helios shell commands

Core:
  help
  help stats
  help tracing
  help rpc
  exit

Interactive:
  stats
      Open the live stats view. Press `q` to return to the shell.
  tracing
      Fetch one tracing snapshot with the current filters.

Stats:
  stats period <ms>
      Set the refresh cadence used by the live stats view.

Tracing:
  tracing limit <n>
      Limit the number of events fetched by `tracing`.
  tracing level <none|error|warn|info|debug|trace>
      Set the minimum tracing level filter.
  tracing targets <prefix-a,prefix-b>
      Restrict tracing to matching targets. Empty means any target.

RPC:
  rpc instance <name>
  rpc func <name>
  rpc payload <hex>
  rpc call
      Configure and invoke an arbitrary remote system call.

Examples:
  stats
  stats period 250
  tracing
  tracing level debug
  tracing targets helios_kernel,helios_riscv
  rpc instance helios:system/stats@0.1.0
  rpc func snapshot
  rpc call

Notes:
  `stats` is the only built-in full-screen view.
  The shell itself stays line-oriented; only commands that benefit from live updates
  switch into a temporary TUI.
