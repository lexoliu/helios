Helios shell commands

Core:
  help
  help stats
  help tracing
  help rpc
  clear
  exit

Interactive:
  pwd
      Print the current remote working directory.
  ls [path]
      List files in the remote debugger filesystem. Paths are resolved from `/`.
  cat <path>
      Print a remote file to the terminal.
  mkdir <path>
      Create a directory in the remote debugger filesystem.
  rm <path>
      Remove a file or an empty directory in the remote debugger filesystem.
  touch <path>
      Create a file if it does not already exist.
  echo [words...]
      Print text. Use `echo ... > /path` or `echo ... >> /path` to write remote files.
  stats
      Open the live stats view. Press `q` to return to the shell.
  tracing
      Stream tracing events with the current filters. Press `Ctrl+C` to return.

Stats:
  stats
      Open the live stats view.

Tracing:
  tracing limit <n>
      Limit the number of events fetched by `tracing`.
  tracing level <none|error|warn|info|debug|trace>
      Set the minimum tracing level filter.
  tracing targets <prefix-a,prefix-b>
      Restrict tracing to matching targets. Empty means any target.

RPC:
  rpc instance <name>
  rpc func <name>
  rpc payload <hex>
  rpc call
      Configure and invoke an arbitrary remote system call.

Examples:
  pwd
  ls
  ls /boot
  mkdir /tmp
  echo hello > /tmp/note.txt
  cat /tmp/note.txt
  touch /tmp/marker
  rm /tmp/marker
  stats
  tracing
  tracing level debug
  tracing targets helios_kernel,helios_riscv
  rpc instance helios:system/stats@0.1.0
  rpc func snapshot
  rpc call

Notes:
  `stats` is the only built-in full-screen view.
  `tracing` stays line-oriented and streams until you interrupt it with `Ctrl+C`.
  The shell itself stays line-oriented; only commands that benefit from live updates
  switch into a temporary TUI.
