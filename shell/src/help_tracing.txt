tracing command help

Commands:
  tracing
      Fetch recent tracing events immediately.
  tracing limit <n>
      Set how many recent events are fetched.
  tracing level <none|error|warn|info|debug|trace>
      Set the minimum tracing level filter.
  tracing targets <prefix-a,prefix-b>
      Restrict events to targets whose names start with one of the prefixes.
  use tracing
      Make tracing the current view.
  refresh
      If tracing is the current view, fetch another event batch.

Examples:
  tracing
  tracing limit 128
  tracing level debug
  tracing targets helios_kernel,helios_riscv
  use tracing
  refresh
