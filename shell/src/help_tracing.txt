tracing command help

Commands:
  tracing
      Stream matching tracing events continuously. Stop with `Ctrl+C`.
  tracing limit <n>
      Set how many recent events are kept in the incremental polling window.
  tracing level <none|error|warn|info|debug|trace>
      Set the minimum tracing level filter.
  tracing targets <prefix-a,prefix-b>
      Restrict events to targets whose names start with one of the prefixes.

Examples:
  tracing
  tracing limit 128
  tracing level debug
  tracing targets helios_kernel,helios_riscv
