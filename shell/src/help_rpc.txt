rpc command help

Commands:
  rpc instance <name>
      Set the remote WIT instance identifier.
  rpc func <name>
      Set the remote function name.
  rpc payload <hex>
      Set the request payload as lowercase or uppercase hexadecimal bytes.
  rpc call
      Invoke the configured remote call and print the raw response as hex.
  use rpc
      Make rpc the current view.
  refresh
      If rpc is the current view, repeat the last configured call.

Examples:
  rpc instance helios:system/stats@0.1.0
  rpc func snapshot
  rpc payload
  rpc call

Example with request payload:
  rpc instance helios:system/tracing@0.1.0
  rpc func recent
  rpc payload <postcard-encoded-filter-and-limit>
  rpc call

Notes:
  `rpc call` is intentionally low-level.
  Use the dedicated `stats` and `tracing` commands when you want decoded output.
